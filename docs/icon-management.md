# 服务图标管理

从 v1.5.0 起，在「账户 → 服务管理 → 添加 / 编辑服务」中配置图片图标；不再需要修改前端源码或重新发布。

## 四种入口

1. **上传图片**：选择 PNG、JPG、WebP、SVG 或 ICO，最大 1 MiB。通过服务端校验后加入图标库，立即预览。
2. **远程图片 URL**：粘贴完整的 HTTP(S) 图片地址并点击「抓取到本站」。服务端下载一次并校验、保存本地副本；卡片不会直接访问远端站点。来源随后换图时，需要重新抓取。无需、也不会携带浏览器中的飞牛登录票据。
3. **选择图标库**：复用 26 个内置官方图标，或之前上传 / 抓取的图片。下拉选择后可查看预览。
4. **已选图标 · 站内路径**：可填写当前实例已有图片的 `/assets/icons/<文件名>` 或 `/media/icons/<文件名>`，保存时必须校验文件存在。这里是本站 URL 路径，不是 NAS 文件系统路径；`/vol1/...`、`file://...`、任意系统文件、目录穿越和符号链接均不支持。

**点击「保存服务」才会应用图标。** 上传或抓取只加入图标库；取消编辑不会改变卡片。上传后取消留下的库图片可以在后续编辑中复用，不会自动删除以免影响其它服务。

「恢复默认图标」只清除该服务的自定义图片；保存后依次使用其内置官方图标、备用字符图标。更换「备用字符图标」不会覆盖已有官方图片；如希望显示自定义图像，请上传或选择图片。

服务图片属于共享目录配置，所有管理账户拥有相同编辑权限；不是个人显示信息、音乐偏好或收藏，后者仍按账户隔离。

## 图片与抓取安全

- 不根据扩展名或 Content-Type 单独判断：验证实际 PNG、JPEG、WebP、ICO、SVG 结构；拒绝伪装图片和过大的内容。
- SVG 不允许脚本、事件处理、HTML 外来内容、DTD / 实体和外部资源引用，直接访问时也施加隔离策略。复杂或依赖外部资源的 SVG 可先转为 PNG 后上传。
- URL 必须是无账号密码的 HTTP(S) 地址。抓取使用有限超时、体积和重定向次数；逐跳校验目标，并固定已校验的解析 IP，同时保持 HTTPS 域名验证。
- 登录后的管理员可抓取家庭 NAS / 局域网服务提供的图片；回环、链路本地、云元数据和其它不安全目标仍拒绝。不会读取代理环境中的认证凭据，也不会绕过来源站点鉴权。
- 401 / 403 通常表示图片来源受登录或应用票据保护。可从自己有权访问的浏览器另存图片后上传；不需要把 Cookie 或密码发给本站。
- 新图片使用内容哈希命名，相同内容去重，换图不会读到旧缓存。卡片图片加载失败时回退默认图片或备用字符。
- 图标库读取和写入均需要登录；写操作沿用 CSRF 防护。图片本身可公开访问，用于公开卡片，**不要上传私人照片、证件或其它敏感图片**。把某张服务卡片设为私密，不等于图标文件也受访问控制。

## 持久化与备份

自定义图片存入 NAS 的 `data/media/icons/library/`，SQLite 入口记录只保存受限的站内引用。代码发布不会覆盖这个目录，发布备份会连同其它 media 一起备份。

JSON 导出包含图片引用，但不包含图片字节。同一实例恢复时保留仍存在的图标引用；跨实例恢复若图片文件缺失，则回退默认图标。完整迁移需同时备份 / 恢复数据库和 media，不能只导入 JSON。

## 飞牛 NAS 默认图标来源

- 用户指定官方地址：https://fnnas.com/favicon.ico
- 原 ICO 的 SHA256：`691526733dc6378247dd3dd3468b23b33ca65bc855b30f87123ba0414ba9625e`
- 解码后选取 144 × 144 图像，无损转为 PNG 并以内容哈希命名，随本站发布；浏览卡片时不热链官方网站。
- 该默认图标对应稳定目录标识 `website:fn`；用户为该服务保存的自定义图片优先，不会被默认图标更新覆盖。
